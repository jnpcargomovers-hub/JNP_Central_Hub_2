The same driver or destination written in different ways splits every report (TRIMBKESWAR · TRAMBAKESHWAR, MEHAMOOD KHAN · Mahmood Khan). Pick the right name for each group and tap Merge:

  • all old records are changed to the right name (Loader, Builty, Delivery, journeys, breakdowns, advances, ledger…)
  • the wrong spellings are remembered — anyone typing them later, and the UTCL portal, get the right name by itself
  • untick a name if it is a different person / place. Same mobile number = same driver.
